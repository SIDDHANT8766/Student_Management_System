# Student_Management_System
A Spring Boot REST API project for managing student records using Spring Data JPA and MySQL. It supports CRUD operations and demonstrates RESTful API development with a layered architecture.

# Features 
  - Add a new student
  - Retrieve all students
  - Fetch a student by ID
  - Update existing student details
  - Delete a student record
  - MySQL database integration
  - RESTful API implementation
  - Layered Architecture (Controller → Repository → Database)
